# 空射 vs 地射弹道导弹 2D 仿真 - 设计计划

> 状态: 方案定稿 (v3); M1-M4 已完成并通过验收 (2025-09-05).
> 本文档是交接基线 / 单一事实来源: 决策记录, 参数基线, 里程碑与验收标准均以本文为准.
> 讨论过程: 用户逐项拍板 (见第 8 节决策记录); 本文件之外的讨论细节不另行保留.

## 1. 目标与问题定义

- 建一套受 RocketPy 设计思想启发 (事件驱动积分, 组件化建模, 时间序列后处理) 的 2D 垂直大圆平面点质量弹道仿真, 用于对比同一技术包线下的弹道导弹从地面垂直发射与从亚音速轰炸机空射的飞行表现.
- 核心问题 (已由用户确认): 对每类平台独立求解助推段设计 (推力曲线形态 + 程序角) 与发射条件, 使满足 "命中速度 >= Vmin" 约束的地表射程最大; 另跑 "两平台共用同一最优推力曲线" 的对照, 隔离平台效应与发动机设计效应.
- 属性: 教学项目, 可解释, 非黑箱; 简化但尽可能拟真; 参数为量级占位值, 不映射任何真实型号; 不做 Monte Carlo / 散布.

## 3. 物理模型 (定稿 v3)

### 3.1 坐标系与运动方程 (球面 2D)

状态量: (r 地心距, theta 射程弧角, v 速度, gamma 航迹角, m 质量). 控制量: 推力方向角 phi (由转向架构约束). 方程:

```
r_dot  = v * sin(gamma)
theta_dot = v * cos(gamma) / r
v_dot  = (F/m) * cos(phi - gamma) - D/m - g(r) * sin(gamma)
gamma_dot = (F/m) * sin(phi - gamma) / v + (v/r - g(r)/v) * cos(gamma)
m_dot  = -m_dot_prop(t)      # 由推力曲线形状决定, 与高度无关
D = 0.5 * rho(h) * v^2 * A_ref * Cd(Mach)
g(r) = mu / r^2
```

phi == gamma 时退化为重力转弯 (推力沿速度方向).

### 3.2 大气: USSA76 分层解析

- 0-86 km 按美标大气 1976 分层公式给出 T(h), p(h), rho(h), a(h); 86 km 以上指数延拓至 ~200 km (该段密度极低, 对轨迹影响可忽略, 仅保证数值连续).
- 用途: 密度进阻力; 压强进喷管推力 F(h); 音速定马赫数 (音速不可假设常数: 10 km 约 299 m/s, 对流层顶 216.65 K 等).
- 验收: 与公开标准表在海平面, 11, 20, 32, 47, 51, 71, 84.852 km 关键点对照, 误差 < 0.5%.

### 3.3 气动: 半经验 Cd(M)

- Cd 为马赫数强函数 (跨声速峰, 超声速平台), 不存在单一常数 Cd; 阻力表达式 D = 0.5*rho*v^2*A*Cd(M) 中 Cd(M) 由几何参数半经验合成:
  - 摩阻: 低马赫区 (湿面积, 按 Re 转捩估计);
  - 底阻: 底部面积比;
  - 波阻: 头部细长度, 弹身长细比, 尾部收缩 (跨声速峰 + 超声速平台).
- 输入几何参数: 直径, 头部细长度, 弹身长细比, 尾部形状, 底面积比; 输出 Cd(M) 插值曲线.
- 量级预期 (合成后校核): 亚声速 ~0.18, 跨声速峰 ~0.6 (M~1.05), M2 ~0.34, M>=4 平台 ~0.26.
- 攻角模型: alpha <= 8 度 (气动线性区); 法向力不做入弹道方程, 诱导阻力 (约 1-2%) 作为已声明修正; 若优化解频繁触碰 alpha 上限, 预案为升级含升力的 3-DOF 方程 (风险预案).
- 稀薄流: 连续介质假设; 80 km 以上密度 < 1e-6 rho0, 自由分子流阻力系数差异对轨迹影响可忽略, 声明即可.

### 3.4 发动机: 一维喷管 F(h) + 推力曲线形状为设计变量

- 推力随高度变化 (背压效应): F(h) = F_vac - p_a(h) * A_e. 由 Isp_SL 与 Isp_vac 两锚点反解 A_e: A_e = m_dot * (Isp_vac - Isp_SL) * g0 / p_a_SL. 质量流率与高度无关.
- 物理设计变量 = m_dot(t) 形状 (对应药柱燃面设计), 而非直接推力: 给定 m_dot(t) 形状与推进剂总质量, 燃烧时间由积分闭合 (int m_dot dt = m_prop).
- 形状族 (2 参): 初始 m_dot 相对均值系数 + 形状类型 (减面 / 恒面 / 助推-续航两段), 每平台独立优化 (方案 B).
- 药柱几何内弹道 (星形/翼柱具体构型) 属下游工程, 范围外; 报告中声明形状族对应常见药柱构型可实现.
- 忽略: 点火瞬态, 熄火拖尾, 推力偏心.

### 3.5 转向与舵效 (TVC 为主 + 气动舵辅助)

- 机理: 气动舵法向力 N = q * S * C_N_alpha * alpha, q = 0.5*rho*v^2; 发射瞬间 v=0 -> q=0, 高空低密度 q 亦趋零, 舵效随高度/速度退化.
- 可用法向过载 = TVC 项 ((F/m)*sin(delta_max)) + 舵项 (q*S*C_N_alpha*alpha_max/m); 分配策略: 优先舵, 不足由 TVC 补; 超出可用上限 -> 该程序角不可行.
- 每时刻记录需求/可用裕度; 每条弹道报告 q(t) 与裕度曲线.
- 弹道方程以推力方向角 phi 为控制 (净效果等价, 攻角小).

### 3.6 约束

- 硬目标约束: v_impact >= 700 m/s.
- 监测项 (默认只监测, M3 决策是否转为硬约束并返工): Max-Q, 轴向/法向过载, alpha, delta, TVC 摆角速率.
- 监测阈值 (占位, 可调): q_max 80 kPa, 轴向 <= 18 g, 法向 <= 5 g, alpha <= 8 度, delta <= 7 度.

### 3.7 忽略项与误差声明 (写入报告附录)

- 地球自转: 2D 严格自洽仅限东/西向大圆; 默认关闭, 报告附误差量级 (数百公里射程下约公里级/百分之几), 留开关.
- 地球扁率 J2: 忽略并声明.
- 风, 大气扰动, 散布, 蒙特卡洛: 全部忽略 (范围外, 用户确认).
- 末端机动, 再入热防护失效: 不做; 仅报峰值冷壁热流 (Sutton-Graves) 作参考指标.
- 点火/分离瞬态: 空射从点火时刻起算 (释放后自由下坠段不计, 声明).
- 多级, 级间分离: 无 (单级).

## 5. 寻优策略 (默认方案, M3 细化决策)

- 正问题引擎: scipy 事件驱动自适应积分 (solve_ivp), 事件: 关机 (m=m_dry), 远地点 (r_dot 过零), 命中 (r=R_e).
- 控制自由度: 每平台 4-5 个参数 (推力形状 2 + 转向程序 2-3); 固体不节流, 无级间, 无末端机动, 控制自由度天然小, 无需重型最优控制.
- L1: 确定性网格扫描 -> 射程-末速前端图 (核心交付图, 同时提供 L2 初值).
- L2: scipy 局部约束优化 (SLSQP / trust-constr), 约束 v_impact >= Vmin.
- L3: scipy differential_evolution 全局交叉验证, 防多峰 (高抛/低伸双解).
- 复杂度: 单弹道积分 < 1 s, 万次级评估分钟量级, 计算可控.
- 注意: 目标函数经事件积分构成, 分段平滑; 网格定位 + 局部收敛 + 全局兜底规避数值差分毛刺.

## 11. RocketPy 复用 (已定: 不克隆, 零依赖自研)

- 结论 (用户拍板): 不克隆 RocketPy 仓库, 不引入 rocketpy 依赖; 仅借鉴其架构思想 (组件化, 事件驱动积分, 时间序列对比).
- 理由:
  1. 范式错位: 6DOF 笛卡尔火箭飞行 API 与本项目 2D 球面极坐标点质量场景不匹配;
  2. RocketPy 无弹道优化层, 其核心价值 (正向积分) 恰是本项目按教学目的自研的最小核心;
  3. 教学可解释性优先, 避免黑箱;
  4. 验证用解析解 (开普勒) + 公开标准大气表 + 公开量级对照, 跨范式交叉验证不成立.
- RocketPy 为 MIT 许可, 许可本身不构成排除原因; 若未来需对照其实现细节, 可临时克隆作离线参考, 但不入库不 import.
